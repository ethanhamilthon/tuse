## Why
A full read-only audit of Tuse v0.13.1 across specs, code, tests, docs, and shipped examples uncovered confirmed bugs, silent validation holes, broken contracts, doc/spec drift, and cross-surface inconsistencies (`H1`–`H6`, `M1`–`M10`, `L1`–`L6`).

All design questions (`Q1`–`Q10` and follow-ups `P1`–`P4`) are now resolved. This proposal specifies a clean, intentionally breaking next release (`protocolVersion: 2`, SQLite schema v4, unified `snake_case` naming, model-scoped effort availability with verbatim wire pass-through, restored `TUSE_GLOBAL_CONFIG`, mid-draft slash commands with explicit picker/space semantics, active sanitized providers in `/config` and `config.get`, `low` default effort on cross-model `llm()`, and Lua/RPC task `log` parity), with zero pending design blockers.

## What Changes
- **Config lookup, validation, and projection (`H2`, `H3`/`Q1`, `M3`/`Q6`, `L2`, `L5`):**
  - Restore `TUSE_GLOBAL_CONFIG` with precedence `-c > ./tuse.lua > $TUSE_GLOBAL_CONFIG > ~/.config/tuse.lua > ~/.config/tuse/init.lua`, honored by `require("global")`, with explicit empty, path-resolution (`~/` and directory -> `<dir>/init.lua`), and fail-fast error semantics.
  - **BREAKING** Expose all active providers (saved and Lua) in `/config` and `config.get` as `providers: [{ name, type, base }]` (and align `tuse providers --json` to `{ name, type, base }` for saved providers), never exposing keys, headers, or extra metadata.
  - Retain raw `ui.theme` token keys and raw link strings in `config.get` while `/config` shows resolved swatches beside raw token values.
  - Replace `deny_unsupported_types(false)` function-stripping with path-aware validation so stray functions/userdata/threads fail with their config path everywhere (removing the `plugins` special case while preserving secret masking under `providers.*`); accept `args = {}` and reject non-dense `args` tables; remove duplicated `history.hide:` prefixes; clear and roll back trusted `package.preload` modules on `/reload`.
- **Model-scoped efforts, no-reasoning models, verbatim wire pass-through, & `llm()` (`H5`/`Q2`/`P2`/`P3`, `M7`/`Q7`):**
  - **BREAKING** Replace hardcoded provider-API effort allowlists (`ApiType::supported_efforts()` / `Client::once` pre-dispatch check) with a unified model-scoped effort resolver: omitted `config.models[].efforts` uses the shared default list `["low", "medium", "high", "xhigh", "max"]`; explicitly empty `efforts = {}` marks a non-reasoning model that sends no reasoning parameters on the wire (never conflated with omitted); explicitly non-empty `efforts = { ... }` is the sole source of truth for that model. Legacy `"default"` is retired.
  - Fallback effort when unset/omitted (or recovering a preserved v3 `state.effort = "default"`) is `"medium"` if available for that model, else the first declared effort in `efforts`, and no effort (`""`) when `efforts = {}`. Use the same resolver across `/models` (skipping effort picker when `efforts = {}`), `model.set` (keeping `model: ""` clearing), `set_session`, `llm`, saved selections, and turn validation.
  - Pass effort strings verbatim on string-field wire protocols (`openai-chat`, `openai-responses`, `anthropic-messages`, non-2.5 `google-gemini` `thinkingLevel`) with no renaming, clamping, or extra availability matrix; omit reasoning parameters when no effort is active (`efforts = {}`); for `gemini-2.5-*` (numeric `thinkingBudget`, no equivalent string field), do not invent mappings or clamp unmapped levels—return an explicit wire-encoding error and document upstream errors truthfully without claiming unverified support.
  - **BREAKING** `llm(prompt, other_model)` with omitted effort sends no reasoning parameter when `other_model` declares `efforts = {}`, otherwise uses `"low"` (validated against `other_model`'s resolved efforts, raising if excluded); omitted/same model inherits session effort.
  - Expand `~/` in `sh(..., { cwd = ... })`.
- **Clean breaking `protocolVersion: 2`, unified naming, state/history split, & SQLite schema v4 (`M1`/`Q4`, `M2`/`Q5`, `L3`/`Q8`/`P1`, `H1`, `M5`, `M8`, `L6.3`/`Q10`, `L6.4`):**
  - **BREAKING** Bump JSON-RPC to `protocolVersion: 2` with unified `snake_case` naming across Lua, storage, config, and JSON-RPC (`title` replacing `name`, `cache_read` replacing `cached`, `cache_write` replacing `cacheWrite`, `context`/`context_window`, `config_path`, `llm_cost`, `requests`, `llm_requests`, `elapsed_ms`, `input_id`). No compatibility bridges or aliases.
  - **BREAKING** Split lightweight `session.state` from `session.history`, retain `session.list`, and retire `session.info`, `session.stats`, `session.snapshot`, `session.resume`, and `model.get` (`-32601`). Document the intentional v2 parity exception for `session.resume` (clients discover IDs via `session.list` and resume via `tuse json -r <id>` or Lua `resume(id)`).
  - **BREAKING** Bump SQLite `user_version` to `4` with flat `Record::Usage` rows (`#[serde(flatten)]` + `cache_read`) and `sessions.usage_cache_read`; no migration or dual-shape reader; atomic `IMMEDIATE` transaction reset preserving `providers` and `state` and rejecting future schema versions (`> 4`).
  - Stop reporting `Last line: failed.` for succeeded no-return background tasks; add `log` to Lua `task_get`/`task_list`/`task_stop` tables; fix `set_session` empty `session_updated`, `tool_step` `Record::Meta` preservation, pending-fork validation, and `started = 1` on history replacement; validate `turn.submit` `data:` image URLs, expand `~/` paths, and enforce `-32602` on wrong-typed optional RPC params; delete dead `cancel_turn(handoff)`/`cancel_pending` code and return `Option<Value>` from `events::to_json`.
- **TUI mid-draft commands, explicit picker/space semantics, keys, theme, & styles (`H6`/`Q3`/`P4`, `L4`/`Q3`/`P4`, `M4`, `L1`, `L6.1`/`Q9`):**
  - Built-in and custom commands (including argument pickers) work anywhere in a TUI draft with no column-0-only restriction. `Enter` with an open command picker and a valid selected item accepts it—immediately executing when complete or transitioning to argument selection—while preserving all text outside the command span.
  - Typing a space after a zero-argument command (such as `/new`) disengages the command picker and prevents accidental execution on ordinary `Enter` (never trimming whitespace into an executable `/new`). Mid-draft prose and `/paths` with no active command picker are preserved and sent cleanly; invalid command args, standalone unknown single-segment commands (`/trace`), and standalone built-in commands with trailing whitespace/words (`/new `, `/new foo`) never execute or send to the model and preserve the draft.
  - Retain all four `ui.input` composer styles (`boxed`, `lines`, `fill`, `bar`) and 33 `ui.theme` tokens (`L6.2`).
  - Route `PageUp`/`PageDown` (without `Shift`) to any open picker with clamping (no wraparound); support `Cmd+X` alongside `Ctrl+X` in `/tasks`; color the idle task spinner with `icons` and count text with `accent`.
- **CLI, prompt, examples, and docs/spec hygiene (`M6`, `H4`, `M9`, `M10`, `L3` docs):**
  - Reject inline `=value` on boolean flags; accept `-`-prefixed values on valued flags unless matching `-h`/`--help`/known flags; validate `tuse help [COMMAND]` and `tuse version`; suggest `--replace` on duplicate `tuse connect`.
  - Sync `prompt.md` and `docs/lua.md` (cancel is not handoff, `task_get` includes `code` and `log`, v2 `session()` fields, `llm()` `low`/no-reasoning rules, fix `in order,.`).
  - Fix `tmux`/`zellij`/`rex`/`orca` examples overwriting title, switch multiplexer examples to `session().title`, update `compaction.lua` to `context`/`context_window` and drop removed `"tool"`.
  - Fix doc drift, add contract-test guards against removed identifiers, and account for malformed baseline spec fragments (`openspec/specs/config/spec.md:97-100` and stray `1` lines) at archive time.

## Impact
- Specs: `config`, `session`, `tui`, `cli` (new), `providers`, `docs`, `examples`.
- Implementation (upon apply): `crates/config`, `crates/api`, `crates/lua`, `crates/core`, `crates/rpc`, `crates/tui`, `crates/cli`, `docs/`, `examples/` (existing unstaged `README.md` and `tuse.lua` remain preserved untouched by this proposal).
- Compatibility: **Intentionally breaking** next release with no compatibility bridges or aliases (`protocolVersion: 2`, retired `session.resume`/`session.info`/`session.stats`/`session.snapshot`/`model.get`, SQLite schema v4 history reset, `session().title`/`context`/`context_window`/`config_path`, `usage.cache_read`, new 5-level effort list + `efforts = {}` no-reasoning + retired `"default"`, `llm()` cross-model `low`/no-reasoning rule, `{ name, type, base }` provider JSON).
- Proposal scope: Proposal-only; only files under `openspec/changes/update-public-api-consistency/` are edited. Baseline `openspec/specs/` and worktree edits stay untouched.
